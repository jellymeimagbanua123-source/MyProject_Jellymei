💻 C++ Console Project
👤 Introduce Yourself

A simple C++ console application that displays my personal profile using functions, variables, conditional statements, and formatted console output.

📖 Overview

The Introduce Yourself program is a beginner-friendly C++ console application that presents my personal information in a clean and organized format. It demonstrates the use of functions, variables, conditional statements, and formatted output while practicing basic C++ programming concepts.

✨ Features
✅ Displays my personal profile
✅ Shows my pet preference (Dog or Cat)
✅ Uses a separate function for displaying information
✅ Clean and organized console output
✅ Beginner-friendly C++ project
